# 🎓 Student Academic Risk Prediction using AI

## 📌 Project Overview
This project predicts student academic risk (Low, Medium, High) using Machine Learning models.

## 📊 Features Used
- Study Time
- Failures
- Absences
- Parent Education (Medu, Fedu)
- Previous Grades (G1, G2, G3)

## 🤖 Models Used
- Logistic Regression
- Decision Tree
- Random Forest

## 📈 Results
- Compared models using accuracy
- Random Forest performed best

## 🧠 Explainable AI
Used SHAP to understand feature importance.

## 🚀 Future Scope
Deploy as web app for schools to monitor student performance.

## 🛠️ Technologies
Python, Pandas, Scikit-learn, SHAP, Google Colab
